# Security and sensitive-input boundary

This repository may be used to inspect older or mixed material. Treat every input as potentially sensitive.

Do not commit or publish:

- secrets, tokens, passwords, or private keys
- private runtime exports
- customer or personal data
- private hostnames, IPs, or internal paths
- production IDs
- private Discord/Telegram exports
- confidential source repositories or logs

Use synthetic/public-safe samples for public issues and screenshots.

Recovery output can contain copied or derived information from its inputs. Review generated artifacts before sharing them.

This repository does not turn recovered material into trusted runtime truth automatically.

For vulnerabilities in the tool itself, use GitHub private vulnerability reporting where available.
